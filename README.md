# India Crime Analytics Dashboard
I have built a basic  interactive Streamlit dashboard for exploring crime data across major Indian cities from 2020 to 2024.

## Features
- Interactive India crime map
- City-wise filtering
- Crime-type filtering
- Gender filtering
- Crime count represented using bubble size
- Crime intensity represented using color
- Interactive Plotly visualization

## Dataset
( i just got it form kaggle :)
The dataset contains crime records with information including 
- City
- Crime Description
- Victim Gender
- Weapon Used
- Latitude
- Longitude
- Year
